# 미사용 모션·모델 출력 복사본 정리

정리일: 2026-11-20 (한국 시간).

게임 소스의 카탈로그, 캐릭터·무기 로딩 코드, 원본 Assets 경로를 대조하여
`Project_Tarkov/x64/Debug/Assets/`에만 남아 있던 과거 파일 36개를 이곳으로 옮겼다.
원래 상대 경로를 유지하며 총 372,787,187 bytes (약 355.5 MiB)다.
디스크에서 삭제한 것이 아니라 실행용 폴더에서 보관용 폴더로 분리한 것이다.

- 이전 모션 FBX 8개: 루트의 대기·걷기·달리기·웅크림 4개와 이전 Locomotion 경로의 같은 종류 4개.
- 대체된 보조 `.anim` 9개: Jump, Land, Prone, RifleHold, RifleIdle, RifleWalk, RifleRun, RifleCrouchIdle, RifleCrouchWalk.
- 통합 캐릭터에 합쳐진 개별 전술복·속옷 메시 13개.
- 위 개별 의상 제작용 PNG 4개와 과거 import JSON 2개.

`moves.json`에 각 파일의 원래 위치, 보관 위치, 크기, SHA-256을 기록했고
이동 후 해시를 확인했다. 복원이 필요하면 기록의 `to` 파일을 `from` 위치로
되돌리되, 현재 파일이 존재하는 경우 덮어쓰기 전에 내용을 대조한다.

현재 사용하는 Mixamo 51개와 Quaternius 라이브러리, 보조 모션·무기 모션,
남녀 통합 메시/텍스처, 공통 리그 `Ch22_nonPBR.fbx`, 무기 모델은 유지했다.
공통 리그 FBX에는 구형 메시도 포함되지만 뼈대 로딩에 필요하므로 파일 전체를
미사용 모델로 처리하지 않았다. 취득 원본·제작 후보·복구 백업·세이브도 유지했다.

정적 대조 결과: 모션·모델 범위의 불필요한 출력 파일 0개, 사용 모션 52개
(Mixamo 51 + Quaternius 1) 및 모델 파일 9개의 출력 복사본 누락/해시 차이 0개.
카탈로그 경로와 원본 해시 대조도 통과했다. 빌드·테스트·게임 실행은 하지 않았다.
