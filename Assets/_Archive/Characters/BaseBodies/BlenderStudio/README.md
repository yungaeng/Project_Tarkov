## Integration status

Candidate source only. No mesh cutting, body replacement, rigging, runtime asset
write, build, test, or game execution was performed for this acquisition.
Body proportions, skin materials, anatomical completeness at the required detail,
UVs, topology and rigging need inspection in Blender before integration. The
downloaded Korean survivor/medic faces must be reviewed against their character
sheets separately; this bundle does not solve face matching automatically.

Alternative: MakeHuman / MPFB core bodies and output are CC0, with configurable
body proportions. Third-party add-on assets can carry different licenses.
Official license: https://www.makehumancommunity.org/about/license.html
and https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md.
