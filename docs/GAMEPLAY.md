# 아이템·플레이어 상태·전투·적 AI

2026-10-08 구현. 사용자 요청에 따라 **빌드·실행·패키지 복원을 하지 않았습니다**. 아래는 코드 기준 동작이며 실제 플레이 검증은 남아 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| I | 인벤토리 열기/닫기 |
| 인벤토리 행 클릭 | 묶음 선택, 상세 정보 표시 |
| Use / Drop 1 / Drop All | 한 개 사용 / 한 개 버리기 / 선택 묶음 전체 버리기 |
| F | 가까이 조준한 월드 아이템 줍기 |
| 1 | 기본 소총 장착/해제 |
| 마우스 왼쪽 클릭 | 단발 사격, 클릭마다 한 발 |
| 마우스 오른쪽 누르기 | 조준, 시야각 75도에서 50도로 축소 |
| R | 2초 재장전 |
| Shift / Ctrl | 스태미나를 사용하는 달리기 / 웅크리기 |
| Q | 종료 |

## 아이템과 상태

- 체력·수분·스태미나는 100으로 시작합니다. 붕대는 체력 +20, 물은 수분 +30이며 최대 100입니다. 최대치 또는 사망 상태에서는 사용하지 못합니다.
- 수분은 초당 0.1 감소하고, 수분 0에서는 초당 체력 1이 감소합니다. 실제 달리기 중 스태미나는 초당 22 감소하고 나머지 시간에는 14 회복합니다. 완전 소진 후에는 20까지 회복해야 다시 달립니다.
- 묶음 선택은 안정적인 ID를 사용합니다. UI는 요청만 생성하고 다음 Update에서 포커스·생존·선택 수량을 재검증합니다. 닫기·포커스 변경·장면 종료 시 요청을 취소합니다.
- 버리기는 전방 1m, 좌우 45도 1m 후보 순서입니다. 발 위치 +0.5m부터 2m 아래 범위의 지면, 아이템 전체를 지지하는 면, 정적 장애물·자기 몸체·기존 아이템과의 겹침 및 벽 통과를 확인합니다. 공중이거나 후보가 없으면 수량을 유지합니다.
- 월드 벡터 저장 공간을 확보한 뒤 수량 제거와 생성이 이루어집니다. 아이템 바닥에는 부동소수점 오차 방지용 1mm 여유가 있습니다.
- 인벤토리와 창 포커스가 모두 활성일 때만 사용·버리기 요청이 가능합니다. 인벤토리를 열어도 적과 상태 변화는 계속됩니다.

## 무기·전투

- 기본 소총 1종을 장착한 상태로 시작합니다. 탄창 30발, 피해 34, 최소 사격 간격 0.15초, 조준 거리 100m입니다. 예비 탄약은 줍기로 확보합니다.
- 카메라 중앙의 조준점을 구한 뒤 플레이어 눈 위치에서 다시 명중을 검사하여 엄폐물 너머 사격을 막습니다. 살아 있는 적 중 가장 가까운 대상에 피해를 적용합니다.
- 사격 시 탄창에서 한 발 차감하고 카메라 반동과 짧은 총기 색상 점멸을 적용합니다. 명중·엄폐물·빗나감·빈 탄창 메시지를 표시합니다.
- 재장전 완료 때 인벤토리 탄약을 필요한 만큼만 탄창으로 옮깁니다. 인벤토리 열기, 포커스 변경, 무기 해제, 사망 시 재장전을 취소하며 탄약은 소비하지 않습니다.
- 체력 0 또는 맵 밖 y < -30 낙하 시 사망합니다. 이동·아이템·사격을 차단하고 사망 안내를 표시합니다. 결과 정산과 재출격 화면은 후속 레이드 단계입니다.

## 적과 전리품

- 적 3명은 두 지점을 순찰합니다. 18m 이내에서 장애물에 가리지 않은 플레이어를 감지하며, 11m 밖에서는 추적하고 안에서는 1.2초마다 피해 8을 줍니다.
- 시야를 잃으면 마지막 위치를 5초 수색한 뒤 순찰합니다. 이동은 기존 캐릭터 충돌을 사용하며 장애물 앞에서는 좌우의 짧은 이동 후보를 확인합니다.
- 적은 플레이어와 같은 FBX 모델·애니메이션을 사용하며 갈색으로 구분합니다. 총기는 부품별 OBJ 에셋을 사용하고 양쪽 사망 시 쓰러지는 애니메이션을 재생합니다. [전투 에셋 가이드](COMBAT_ASSETS.md)를 참고하세요.
- 적 사망 후 지면에 닿으면 탄약 20개를 한 번 생성합니다. F 줍기의 기존 거리·가림·인벤토리 용량 검증을 그대로 사용합니다.
- 현재 AI는 국소 장애물 회피 방식으로 복잡한 미로를 위한 경로 탐색은 포함하지 않습니다. 캐릭터 사이의 동적 충돌, 총성·피격 사운드는 후속 범위입니다.

## 구조

- PlayerVitals.h: 플레이어 상태, 회복·피해·스태미나.
- InventoryActions.h/cpp: UI 요청 검증 및 아이템 사용·버리기 조정.
- CombatSystem.h/cpp: 소총, 재장전, 명중, 적 상태 및 사망 전리품.
- RaidScene: 입력 → 아이템 요청 → 이동·상태 → 전투·AI → 줍기 순서. HUD는 렌더 단계에서 다음 프레임 요청만 생성합니다.

## 추후 실행 확인

1. 붕대 2개/체력 50에서 사용 시 70/1, 체력 95에서는 100/1, 최대치에서는 미소비.
2. 물 사용 시 수분 100 제한, 탄약 Use 비활성, 사용 후 마지막 묶음 선택 해제.
3. Drop 1/All 후 재줍기 총수량 보존, 공중·벽·겹침·지면 없음 시 미소비.
4. 클릭 직후 I 또는 Alt+Tab 시 요청 취소, 동일 묶음 연속 조작과 빈 목록 안전성.
5. 30발 사격 후 빈 탄창, 70발 예비 탄약으로 재장전 후 탄창 30/예비 40.
6. 재장전 도중 인벤토리·무기 해제·포커스 상실·사망 시 탄약 보존.
7. 엄폐물 앞/뒤 사격, 가장 가까운 적 명중, 3발 명중 후 적 사망과 전리품 1회 생성.
8. 적 감지·추적·공격·시야 상실·수색 종료, 벽 충돌과 사망 후 공격 중지.
9. 스태미나 소진·회복, 탈수 피해, 사망 후 모든 게임 동작 차단.

정적 확인과 실제 실행 검증을 구분하며 위 항목의 실행 통과를 주장하지 않습니다.
