# 총기·공유 캐릭터·사망 에셋

2026-10-08 추가. 빌드와 게임 실행은 수행하지 않았습니다.

## 에셋

- `Assets/Models/Weapons/Rifle.obj`: 이번 작업에서 제작한 저폴리 소총. 총열·총구 제퇴기·가늠쇠·가늠자·상부 레일·핸드가드·개머리판·권총 손잡이·방아쇠울을 포함합니다.
- `Magazine.obj`, `Bolt.obj`, `MuzzleFlash.obj`: 분리된 탄창·노리쇠·총구 화염 메시입니다. 모두 미터 단위, +Y 위, +Z 총구 방향이며 원점은 발사 손잡이입니다.
- `Assets/Animations/Weapons/*.anim`: 대기 흔들림, 조준 전환, 사격 반동·노리쇠 왕복, 2초 탄창 교체, 장착·해제 키프레임입니다.
- `Assets/Animations/Characters/RifleHold.anim`, `RifleReload.anim`: 기존 골격에 적용하는 총기 파지와 재장전 상체 포즈입니다.
- `Assets/Animations/Characters/Death.anim`: 1.25초 동안 몸통·머리·팔·다리가 변형되고 몸 전체가 뒤로 쓰러지는 사망 클립입니다. 마지막 키프레임을 유지합니다.

신규 OBJ와 `.anim` 데이터는 프로젝트용으로 직접 제작했으며 외부 다운로드 에셋을 포함하지 않습니다. 기존 캐릭터와 FBX 애니메이션에는 기존 이용 조건이 유지됩니다.

## 플레이어와 적

적도 `Ch22_nonPBR.fbx`, `Idle.fbx`, `Walking.fbx`, `Fast Run.fbx`, `Crouched Walking.fbx`를 플레이어와 동일하게 로드합니다. 적 구분을 위해 몸체 색만 갈색으로 지정합니다. 모델 파일을 복제하지 않으며 모델·클립·정적 VBO·인덱스 버퍼는 공유하고 각 캐릭터의 골격 자세·재생 시간·본 행렬 버퍼는 독립적입니다. AI의 현재 행동은 대기·이동을 사용하고 달리기·웅크리기 애니메이션 경로도 공유합니다.

총기는 변형된 오른손 본의 위치에 부착합니다. 장착 중 플레이어는 카메라의 수평 조준 방향으로 회전하고, 공격하는 적은 플레이어를 향해 회전합니다. 적의 사격에도 총기 반동과 화염이 재생됩니다. 시각 효과는 탄약·명중·전리품 데이터를 변경하지 않습니다.

플레이어와 적은 같은 사망 클립을 사용합니다. 사망 순간의 현재 골격 자세를 캡처해 이동·호흡 애니메이션을 중단하고, 그 자세에 사망 키프레임을 적용합니다. 기존 캐릭터 메시 자체가 사망 에셋으로 남으며 별도 상자 시체를 생성하지 않습니다. 지지면 아래로 내려가지 않도록 회전된 메시 최저점을 보정하고 최종 자세에서는 추가 CPU 스키닝과 본 행렬 업로드를 중단합니다. 래그돌이나 주변 벽에 맞춘 시체 물리 시뮬레이션은 포함하지 않습니다.

## 애니메이션 파일 형식

한 줄은 `채널 초 이동X 이동Y 이동Z 회전X 회전Y 회전Z`입니다. `#`는 주석입니다. 모든 채널은 0초에서 시작하고 시간이 증가해야 하며 회전은 도 단위입니다. 이동 단위는 총기·Root는 미터, 골격 채널은 FBX 모델 단위(센티미터)입니다. 채널 이름은 네임스페이스 없는 기존 본 이름 또는 Weapon/Magazine/Bolt/Root입니다.

키 사이에는 부드러운 보간을 적용하며 한 번 재생하는 동작은 마지막 키에서 멈춥니다. 대기는 호출 측에서 반복 시간을 계산합니다. 재장전 시각 시간은 게임의 남은 2초 타이머에서 가져오므로 취소 시 탄창과 포즈가 기본 상태로 돌아갑니다. 추가 라이브러리 없이 기존 Assimp/GLM/OpenGL을 사용합니다.

총기 메시·클립은 약한 참조 캐시로 공유합니다. 각 캐릭터는 독립된 시각 상태를 가지며 마지막 사용자가 해제되면 OpenGL 컨텍스트가 살아 있는 장면 종료 단계에서 GPU 메시도 해제합니다.
