# 입력·자원 관리 검증

## 수동 실행 확인

[빌드 가이드](BUILD.md)에 따라 외부 라이브러리를 준비한 뒤 확인합니다.

| 상황 | 기대 결과 |
| --- | --- |
| I키로 커서 해제 → 이동 → 다시 I키 | 복귀 순간 시점이 크게 회전하지 않음 |
| 이동 키를 누른 채 Alt+Tab | 비활성 창에서 이동하지 않음 |
| I/F11 키를 누른 상태로 포커스 복귀 | 복귀 자체가 새로운 토글로 처리되지 않음 |
| F11 전환 중 마우스 위치 변경 | 전환 직후 누적 이동량이 시점에 반영되지 않음 |
| 창 최소화 | 높이 0인 프레임버퍼로 투영 행렬을 계산하지 않음 |
| 실행 중 셰이더 문법 오류 저장 | 오류 출력 후 기존 셰이더로 계속 표시, 같은 변경을 매 프레임 재컴파일하지 않음 |
| 셰이더 수정 후 다시 저장 | 성공하면 새 프로그램으로 교체 |
| 실행 중 셰이더 파일 일시 이동 후 복원 | 파일 시간 조회 예외로 종료되지 않음 |
| 필수 셰이더/모델을 찾을 수 없는 작업 폴더에서 실행 | 오류를 기록하고 자원을 정리한 뒤 실패 코드로 종료 |
| 장면 재로딩·종료 | 장면의 그래픽 자원을 OpenGL 컨텍스트 파괴 전에 해제 |

Mesh는 복사할 수 없고 이동으로 소유권을 이전합니다. Shader와 Texture도 복사를 금지합니다.
그래픽 객체의 소멸 및 Reset 호출에는 생성에 사용한 유효한 OpenGL 컨텍스트가 필요합니다.
Application은 장면 종료와 소멸을 완료한 뒤 입력 및 창을 종료합니다.

## 현재 검증 한계

2026-10-05 전체 빌드는 MSBuild 실행 환경의 PATH/Path 중복 문제로 중단되었습니다.
MSVC 직접 구문 검사도 외부 헤더 glad/glad.h를 찾을 수 없어 중단되었습니다.
따라서 게임 전체의 컴파일·링크 성공, 실제 화면 동작, GPU 자원 해제는 아직 검증하지 못했습니다.

## 2026-10-08 구조 정리

입력·카메라·캐릭터 표현 분리와 폴더 이동을 반영했습니다. 사용자 요청에 따라 빌드·실행하지 않았습니다. 경로 및 프로젝트 등록의 정적 확인은 컴파일·실행 검증을 대체하지 않습니다.

## 웅크리기 충돌 수동 확인

이번 변경은 빌드·실행하지 않았습니다. 다음 실행 시 아래 항목을 확인합니다.
현재 기본 맵에는 낮은 천장이 없으므로 검증용 맵에 바닥 위 여유 높이가 1.3인 천장 상자를 배치합니다.
기본 바닥 상단이 -0.9이므로 예를 들어 `{{-8, 0.4f, -3}, {-4, 0.8f, 1}}`을 사용하면 됩니다.

| 상황 | 기대 결과 |
| --- | --- |
| 열린 공간에서 Ctrl 누름·해제 | 발 위치가 바뀌지 않고 충돌 높이가 1.1·1.8로 전환 |
| 서서 높이 1.3의 통로 진입 | 천장 옆면에 막힘 |
| 웅크리고 같은 통로 진입 | 통과 가능 |
| 천장 아래에서 Ctrl 해제 또는 Shift 입력 | 웅크림과 속도 2.5, 낮은 카메라, 웅크림 애니메이션 유지 |
| Ctrl을 놓은 채 통로 밖으로 이동 | 몸체 전체가 천장을 벗어나면 다음 입력 갱신에서 일어섬 |
| 몸체의 일부만 천장 아래에 남음 | 중심점이 밖이어도 일어서기 차단 |
| 서 있는 몸체가 천장에 정확히 접촉 | 겹침이 없으므로 일어서기 허용 |
| 웅크린 채 벽 충돌·낙하·착지 | 높이 1.1을 사용하며 중력과 지면 판정 유지 |
| 천장 아래에서 I 또는 Alt+Tab 후 복귀 | 천장을 관통하지 않고 실제 자세 유지 |

## 2026-10-08 아이템·전투·AI 추가

빌드·실행하지 않았습니다. 신규 소스 등록 및 참조를 정적으로 점검하며, 실행 검증 시나리오는 [GAMEPLAY.md](GAMEPLAY.md)의 추후 실행 확인 항목을 사용합니다.
