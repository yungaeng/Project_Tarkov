# 입력·자원 관리 검증

## 자동 입력 테스트

Developer PowerShell for VS 2022에서 저장소 루트 기준으로 실행합니다.

```powershell
.\tests\run-input-tests.ps1
```

실제 Input.h를 컴파일하며, 테스트 전용 GLFW 및 vec2 대역으로 이벤트와 좌표를 제어합니다.
대역 헤더는 테스트 빌드에만 포함되며 게임 프로젝트에는 등록하지 않습니다.
생성 파일은 임시 폴더의 tarkov-input-tests에 저장합니다.

검사 대상:

- 초기화 전·종료 후 호출 및 잘못된 키 코드.
- 키 눌림, 유지, 해제에 따른 단발 이벤트.
- 일반 마우스 이동량과 상하 부호.
- 커서 해제 중 이동 후 다시 캡처했을 때 첫 이동량 초기화.
- 포커스 상실 중 입력 차단과 복귀 시 토글 키 오작동 방지.
- 한 번의 이벤트 처리에서 포커스를 잃었다가 되찾는 경우.
- 전체화면 전환에 사용하는 마우스 기준점 초기화.
- 입력 종료 시 콜백 해제와 재초기화.

2026-10-05: MSVC 14.44.35207로 직접 컴파일하고 실행해 통과했습니다.
GPU, 운영체제의 실제 커서 처리, 그래픽 자원 해제를 검증하는 테스트는 아닙니다.

## 수동 실행 확인

[빌드 가이드](BUILD.md)에 따라 외부 라이브러리를 준비한 뒤 확인합니다.

| 상황 | 기대 결과 |
| --- | --- |
| I키로 커서 해제 → 이동 → 다시 I키 | 복귀 순간 시점이 크게 회전하지 않음 |
| 이동 키를 누른 채 Alt+Tab | 비활성 창에서 이동하지 않음 |
| I/F11 키를 누른 상태로 포커스 복귀 | 복귀 자체가 새로운 토글로 처리되지 않음 |
| F11 전환 중 마우스 위치 변경 | 전환 직후 누적 이동량이 시점에 반영되지 않음 |
| 창 최소화 | 높이 0인 프레임버퍼로 투영 행렬을 계산하지 않음 |
| 실행 중 셰이더 문법 오류 저장 | 오류 출력 후 기존 셰이더로 계속 표시, 같은 변경을 매 프레임 재컴파일하지 않음 |
| 셰이더 수정 후 다시 저장 | 성공하면 새 프로그램으로 교체 |
| 실행 중 셰이더 파일 일시 이동 후 복원 | 파일 시간 조회 예외로 종료되지 않음 |
| 필수 셰이더/모델을 찾을 수 없는 작업 폴더에서 실행 | 오류를 기록하고 자원을 정리한 뒤 실패 코드로 종료 |
| 장면 재로딩·종료 | 장면의 그래픽 자원을 OpenGL 컨텍스트 파괴 전에 해제 |

Mesh는 복사할 수 없고 이동으로 소유권을 이전합니다. Shader와 Texture도 복사를 금지합니다.
그래픽 객체의 소멸 및 Reset 호출에는 생성에 사용한 유효한 OpenGL 컨텍스트가 필요합니다.
Application은 장면 종료와 소멸을 완료한 뒤 입력 및 창을 종료합니다.

## 현재 검증 한계

2026-10-05 전체 빌드는 MSBuild 실행 환경의 PATH/Path 중복 문제로 중단되었습니다.
MSVC 직접 구문 검사도 외부 헤더 glad/glad.h를 찾을 수 없어 중단되었습니다.
따라서 게임 전체의 컴파일·링크 성공, 실제 화면 동작, GPU 자원 해제는 아직 검증하지 못했습니다.
