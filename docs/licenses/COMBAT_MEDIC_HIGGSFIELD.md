## 상업적 이용 확인 범위

[Higgsfield 공식 안내](https://higgsfield.ai/creator-hub/help-center/account/who-owns-my-generations-and-can-i-use-them-commercially)는 생성물의 상업적 이용을 허용한다고 설명한다. 이는 참조 이미지와 제3자 권리를 자동으로 확보해 주는 보증이 아니다. 원본 시트의 제작 출처와 상업적 변형·사용 권한 증빙은 아직 제공되거나 확인되지 않았다. 실제 생성 시점의 [서비스 약관](https://higgsfield.ai/terms-of-use-agreement)과 적용되는 제공자 조건도 함께 보존해야 한다.

[ICRC 공식 안내](https://www.icrc.org/en/copyright-and-terms-use)는 적십자·적신월 표장의 사용이 제한됨을 설명한다. 따라서 상업용 제작 요청에는 해당 표장을 독자적인 하트로 교체하도록 지정했다. 생성물에서 유사 표장이 남지 않았는지 별도 검토가 필요하다.

현재 상태를 상업 배포 가능 모델 확보 또는 캐릭터 권리 확인 완료로 기록하지 않는다.
