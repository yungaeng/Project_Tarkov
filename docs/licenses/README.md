# 라이선스 및 상업 배포 준비

기준일: 2026-11-11

이 문서는 라이선스 확인 사항과 에셋 교체 계획을 개발 기능 문서와 별도로 관리한다. 실제 제3자 라이선스 원문과 설치 패키지 버전은 [Open_Source_Licenses.txt](../../Open_Source_Licenses.txt)를 참고한다. 아래 계획은 사용자와 합의한 작업 방향이며, 교체 완료 또는 상업 배포 승인 기록이 아니다.

## 현재 상태

C++·OpenGL·GLFW 기반 기술 구성과 에셋의 권리는 별도로 관리한다. 라이브러리 고지는 기존 원문 파일에 보존한다. 에셋은 아래 교체 및 확인 작업이 남아 있다.

### 캐릭터 — 직접 제작한 에셋으로 교체 예정

사용자는 직접 만든 캐릭터로 교체할 계획이다. 현재 남캐·여캐 모델의 변환 기록에는 Koikatsu 추출 경로가 있고, 결합한 머리 VRM에는 비영리·재배포 금지·수정 금지 메타데이터가 있다. 아직 교체 완료로 처리하지 않는다.

교체 시 몸체·머리·의상·텍스처 각각의 제작 출처를 기록한다. 외부 부품을 사용한다면 해당 부품의 허가 범위도 확인한다. 새 모델로 바꾼 뒤 실제 배포 폴더에서 기존 모델·텍스처와 불필요한 원본을 제외한다.

### 모션 FBX — 사용자 직접 제작본으로 교체 예정

사용자는 현재 외부 모션 FBX를 추후 직접 제작한 모션으로 교체할 예정이다. 대상은 Assets/Animations/Characters/Locomotion/의 Idle.fbx, Walking.fbx, Fast Run.fbx, Crouched Walking.fbx다.

교체 전에는 기존 파일의 출처 확인 항목을 유지한다. 교체 후 게임의 로딩 경로와 배포 에셋을 새 파일 기준으로 정리한다. 별도 모델인 Assets/Models/Player/Ch22_nonPBR.fbx는 모션 교체만으로 제거됐다고 간주하지 않고 실제 사용 여부와 교체 여부를 확인한다.

### UI 이미지 — 일부 아이콘만 교체 예정

Assets/UI/items.png는 Codex의 이미지 생성 도구로 제작한 4×4 아이콘 아틀라스다. [제작 기록](../../Assets/UI/README.md)에 따르면, 생성 후 사용자 제공 상품 사진을 참조해 **2행 3열 속옷 아이콘**을 수정했다. 행과 열은 1부터 센다.

이번 대화에서 특정한 외부 상품 사진 관련 확인 대상은 이 아이콘이다. 해당 사진 및 사진을 반영한 기존 아이콘을 참조하지 않은 새 디자인으로 이 칸을 교체하는 방향으로 정리한다. 나머지 UI 전체를 다시 제작하는 작업은 계획에 포함하지 않는다.

교체할 때는 4×4 배치와 아이템 순서, 다른 칸을 유지하고 새 생성·제작 이력을 기록한다. 완료 후 기존 참조 사진 기반 아이콘이 배포 파일에 남지 않았는지 확인한다. 이는 해당 참조 이미지와 관련된 항목을 해결하는 작업이며, UI 전체에 대한 포괄적인 권리 보증이나 새로운 MIT 라이선스 부여를 뜻하지 않는다. 생성 당시 적용 서비스 약관 등 별도 조건은 유지한다.

## 배포 문서 관리

Open_Source_Licenses.txt는 라이브러리 고지 원문을 보존하는 파일이다. 이 문서는 교체 계획과 미완료 사항을 관리한다. 라이선스 문구를 적는 것과 사용 허가를 확보하는 것은 별개이므로 교체/허가 증빙이 확인된 항목만 완료로 변경한다. 개발용 x64/Debug 구성은 유지하고, 출시 패키지의 런타임 재배포 조건은 원문 파일에 기록한 기준에 따라 별도로 확인한다.

## 문서대로 진행한 뒤에도 남는 출시 확인 사항

이 문서는 라이선스 정리 및 에셋 교체 계획이다. 계획을 기록하거나 고지 파일을 포함하는 것만으로 상업 배포 권리 확보, 플랫폼 승인 또는 게임 품질 검증이 완료되는 것은 아니다.

### 실제 배포 파일과 권리 증빙

캐릭터·모션 교체 후에는 소스 폴더뿐 아니라 실제 출시 패키지도 확인한다. 이전 빌드에서 복사된 기존 모델·텍스처·FBX가 남아 있지 않아야 한다. Ch22_nonPBR.fbx는 별도 확인 대상으로 유지한다. 라이브러리 버전과 실제 배포 DLL·정적 링크 구성도 고지 목록과 대조한다.

직접 제작한 캐릭터에 외부 의상·머리·텍스처가 포함되면 그 구성 요소의 상업 이용 및 게임 내 배포 조건도 확인한다. 제작 원본, 취득 출처, 허가 문구와 적용 버전을 보관한다. 라이선스 고지 자체가 사용 허가를 대신하지 않는다.

UI 2행 3열 교체는 현재 특정된 상품 사진 참조 문제를 처리하는 범위다. 다른 UI 전체의 권리를 검증했다거나 추가 확인이 전혀 필요 없다는 의미가 아니다. 생성 서비스의 적용 약관과 외부 참조물 사용 여부는 별도로 관리한다.

### 출시 런타임과 설치 구성

개발·테스트는 기존 x64/Debug 구성을 유지한다. 고객용 출시 패키지는 별도로 준비하고, 허용된 VC++ Redistributable 및 필요한 런타임만 포함한다. 재배포가 허용되지 않는 Debug 런타임을 개발 폴더에서 그대로 복사하지 않는다. 현재 설치한 Visual Studio 에디션과 개인/조직 사용 자격도 출시 시점에 확인한다.

근거: [Visual Studio 2022 재배포 조건](https://learn.microsoft.com/visualstudio/releases/2022/redistribution), [Visual Studio 라이선스 안내](https://www.microsoft.com/licensing/guidance/Visual-Studio).

### 판매 국가와 플랫폼 심사

국내 배포를 계획하면 출시 형태에 적용되는 등급분류 절차, 담당 기관 또는 플랫폼의 자체등급분류 경로와 예외 적용 여부를 확인한다. 이 문서 작성으로 등급분류를 신청하거나 승인받은 것은 아니다. 실제 게임의 폭력·노출 등 콘텐츠와 배포 지역에 맞춰 준비한다.

Steam 출시 시에는 당시 콘텐츠 설문에 따라 플레이어가 접하는 AI 생성 이미지의 사용과 성인·폭력 콘텐츠 등을 정확하게 신고한다. AI 생성 사용 기록과 에셋 교체 이력을 유지하고, 심사 제출 내용과 실제 출시 콘텐츠를 일치시킨다. 다른 플랫폼을 선택하면 해당 플랫폼 조건을 별도로 확인한다.

근거: [게임콘텐츠등급분류위원회 안내](https://www.gcrb.or.kr/Institution/EtcForm01.aspx), [Steamworks 콘텐츠 설문](https://partner.steamgames.com/doc/gettingstarted/contentsurvey). 링크의 조건은 출시 시점에 다시 확인한다.

### 실행 품질 검증

그동안 요청에 따라 빌드·실행 검증을 생략한 코드 변경이 있다. 라이선스 정리와 게임 정상 작동 여부는 별개다. 출시 전 별도 검증 작업에서 빌드, 주요 플레이 흐름, 저장·불러오기, 에셋 로딩 및 설치를 확인해야 한다. 특히 개발 도구가 없는 대상 Windows 환경에서 필요한 런타임과 파일만으로 실행되는지 확인한다.

이 항목은 향후 출시 준비 계획이며 현재의 빌드·테스트 생략 지시를 변경하거나 검증을 실행하라는 지시가 아니다.
