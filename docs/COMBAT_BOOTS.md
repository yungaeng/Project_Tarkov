# 검정색 군화

- 신발 슬롯은 기존 장비 뒤에 추가했으며, 아이템 ID는 10, 장비 비트는 7입니다.
- 군화는 한 켤레당 1.4kg이고 중첩되지 않습니다. 새 캐릭터는 한 켤레를 기본 착용하며 창고에 중복 지급하지 않습니다.
- 기존 저장 파일의 장비는 유지됩니다. 기존 캐릭터도 필드 드롭이나 적의 전리품에서 획득하여 착용할 수 있습니다.
- 은신처의 신발 슬롯과 레이드 인벤토리에서 착용·해제하며, 사망 시 다른 의류처럼 전리품으로 이전됩니다.
- `Tactical/black_boots.mesh`는 별도 편집용 스킨 메시이며 실제 표시는 통합 `character.mesh`에 포함됩니다. 검정 가죽, 밑창, 끈, 발목 패딩과 바닥 돌기를 포함합니다.
- `Tactical/black_boots_material.png`의 색상은 캐릭터 아틀라스의 (3328, 2336), 256×64 영역에도 저장됩니다.
- `Tools/create_combat_boots.py`로 재생성합니다. 전술복 전체를 재생성했다면 마지막에 이 도구를 다시 실행합니다.
- TKCHAR05 형식은 군화 그룹 8을 추가합니다. 이전 캐릭터 메시 형식도 읽습니다.
- 은신처 저장 버전은 9이며 이전 버전의 재고 수와 무기 배치 ID를 변환합니다.
- 게임 빌드 및 실행 검증은 하지 않았습니다.
