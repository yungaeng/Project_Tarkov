# 캐릭터 애니메이션

Animation/CharacterVisual에서 Character의 이동 결과와 자세에 따라 애니메이션을 선택합니다.

| 상태 | 재생 |
| --- | --- |
| 정지 | Idle.fbx, 3.5초 호흡 루프 |
| WASD 이동 | Walking.fbx |
| Shift 이동 | Fast Run.fbx |
| Ctrl 이동 | Crouched Walking.fbx |
| Ctrl 정지 | 웅크리기 첫 자세에 코드 기반 호흡 추가 |

키 입력이 있어도 벽에 막혀 실제 수평 이동이 없으면 대기 상태로 전환합니다.
공중에서는 보행 동작을 재생하지 않으며 별도 낙하 동작은 아직 없습니다.
상태 변경은 0.15초 동안 위치·크기 보간과 회전 slerp로 이어집니다.
캐릭터는 실제 이동 방향으로 회전합니다.

## 구성

- SkeletalAnimation: Assimp로 읽은 모델·클립을 공유하고 캐릭터별 본 포즈와 행렬을 계산합니다. 일반 프레임의 정점·법선 변형은 GPU에서 처리합니다.
- Mesh::CreateSkinned: 고유 정점·인덱스·본 가중치를 공용 정적 버퍼에 저장합니다. 캐릭터별로는 본 행렬 버퍼만 갱신합니다.
- CharacterVisual: 상태 선택, 본 행렬 업로드, 시야 밖 렌더링 제외를 담당합니다. RaidScene은 프레임 공통 셰이더 데이터를 한 번 설정합니다.
- 루트와 Hips의 수평 이동은 고정하여 물리 이동과 애니메이션 이동이 중복되지 않게 합니다.
- 애니메이션 키가 없는 말단 본은 기본 로컬 변환을 유지하고 부모를 따라갑니다.
- 네임스페이스를 제외한 본 이름을 매칭합니다. 다른 체형·골격에 대한 범용 리타게팅은 아닙니다.

기존 삼각형 펼침 방식은 164,883개 정점을 사용했습니다. 현재는 동일 정점 병합과 인덱스 렌더링을 사용하며, 본 영향 개수를 잘라내지 않는 GPU 스키닝을 적용합니다. CPU 스키닝은 사망 동작 중 바닥 보정에만 사용합니다. 최적화 범위와 확인 항목은 [성능 가이드](PERFORMANCE.md)를 참고하세요.

## 새 Idle.fbx

Assets/Idle.fbx는 프로젝트의 Walking.fbx와 Ch22_nonPBR.fbx에서 동일한 골격을 유지하여 생성했습니다.
하체는 기본 서 있는 자세, 상체는 걷기 시작 자세를 바탕으로 작은 호흡 회전을 적용합니다.
30fps, 106개 키 시점, 3.5초 루프이며 시작과 끝 값이 일치합니다.
메시와 텍스처가 없는 애니메이션 전용 FBX로 기존 캐릭터 모델에 적용해야 합니다.
크기는 311,234바이트입니다. 원본 에셋의 이용 조건은 그대로 적용됩니다.

생성된 Idle.fbx는 에셋으로 포함되어 있습니다. 생성 도구와 자동 테스트는 저장소 정리 과정에서 제거했습니다.
게임에서 대기·걷기·달리기·웅크리기 전환과 호흡 동작을 확인하세요.

## 총기·적·사망 확장

플레이어와 적은 CharacterVisual을 공유합니다. 총기 OBJ 및 키프레임, 파지·재장전 포즈, 사망 클립과 마지막 자세 유지 방식은 [전투 에셋 가이드](COMBAT_ASSETS.md)를 참고하세요. 빌드·게임 실행은 하지 않았습니다.

## 소총 자세별 모션 확장
- RifleHold: 오른손/왼손 손목 각도 보정.
- RifleIdle: 3초 호흡, RifleWalk: 0.8초 어깨 흔들림.
- RifleRun: 0.6초 낮은 파지와 상체 기울기.
- RifleCrouchIdle: 2.8초 작은 호흡, RifleCrouchWalk: 1.1초 절제된 상체 움직임.
- RifleAim: 조준 시 팔꿈치/어깨 파지 강화. 조준 중에는 달리기 상체보다 조준 자세 우선.
- RifleRecoil: 발사 이벤트에 맞춘 0.18초 상체/팔 반동과 복귀.
- Weapons/Run 및 Crouch: 자세별 소총 위치·회전과 흔들림.
- 기존 FBX 하체 모션을 유지하고 새로운 .anim 로컬 본 회전을 상체에 겹칩니다.
  새로운 FBX 모션 캡처 파일을 만든 것은 아닙니다.
- 프레임 시간 기반 지수 보간으로 자세 가중치를 전환하고, 조준 중 흔들림을 줄입니다.
  기존 재장전·사망·무장 소유 여부와 원거리 포즈 갱신 제한을 유지합니다.
- 두 손 IK는 아직 없으며 왼손과 총열의 정확한 접촉은 실행 후 튜닝이 필요합니다.
- 검증: 18개 .anim 파일의 행 형식, 초기 키, 증가하는 타임스탬프 및 프로젝트 XML 확인.
  요청에 따라 빌드·실행은 하지 않았습니다. 자세별 손 밀착, 관절 꺾임, 전환 및 재장전 겹침은 미확인입니다.

## 2026-10-20 자세 및 1인칭 카메라 보정

- 대기·걷기·달리기 상체를 기본 골격 기준으로 보정하고, 이동 중 상체 보정 주기를 FBX 다리 주기에 맞춥니다. 실제 수평 이동 속도에 따라 재생 속도를 조절합니다.
- 앉은 대기는 별도 쪼그린 자세를 사용합니다. 쪼그려 걷기는 같은 골반 높이에서 기존 다리 보행을 유지합니다.
- 엎드리기는 낮은 골반과 벌어진 다리, 지면 가까운 팔꿈치를 사용합니다. 포복 중 보조손은 총기 IK에서 지면 짚기 동작으로 전환하며 조준·발사·재장전 때는 총기 그립을 우선합니다.
- 1인칭 카메라는 애니메이션의 머리 위치를 따릅니다. 머리·목·몸통·어깨의 보수적인 구형 충돌 영역에 카메라 여유 반경을 더해 전방으로 밀어냅니다. 자세 전환 후 최신 포즈로 다시 계산합니다. 이는 캐릭터 몸 관통 방지이며 월드 지형 카메라 충돌의 대체 구현은 아닙니다.
- 참고: [미 육군 개인 이동 자세 자료](https://www.army.mil/article/289567/close_fighting_fundamentals_tactical_level_training_considerations_to_prepare_for_uncertain_future_battlefields), [미 해병대 사격 자세 소개](https://www.marines.mil/News/News-Display/Article/2347758/camp-lejeune-marines-take-aim-with-new-annual-rifle-qualifications-to-develop-m/). 낮은 포복과 정지 자세의 구분을 참고했으며 각도·보행 주기는 게임 모델에 맞춘 수작업 값입니다. 해병대 PDF 본문은 서버 접근 제한으로 직접 열람하지 못했습니다.

검증: Debug x64 컴파일 및 링크, 실제 OpenGL 렌더러의 7개 자세 검사와 14개 화면 캡처, 실행 파일 시작 및 셰이더 로딩 확인. 검사 소스는 `Tools/validate_tactical_motion.cpp`입니다. 자동 렌더링 검사는 1인칭 몸 숨김을 비활성화합니다. 모든 지형·시점 조합의 수동 플레이 검증을 의미하지 않습니다.

로컬 MSVC의 MSPDB140.DLL 오류 때문에 이번 검증 빌드만 `.build/qa/no-link-pdb.targets`로 링크 디버그 심볼 생성을 비활성화했습니다. 프로젝트의 기본 디버그 설정은 변경하지 않았습니다.
