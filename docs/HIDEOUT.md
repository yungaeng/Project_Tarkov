# 은신처와 출전 장비

게임은 은신처 장비 준비 화면으로 시작합니다. 3D 은신처 공간 대신 기존 ImGui HUD 기반 화면입니다.

## 조작
1. 창고의 RIFLE 카드를 캐릭터 PRIMARY / RIFLE 슬롯으로 드래그해 장착합니다.
2. 장착한 소총 카드를 창고 카드 또는 DROP HERE TO STORE 영역으로 드래그하면 소총과 탄창 잔탄을 보관합니다.
3. 창고의 붕대·물·탄약 카드를 CARRIED SUPPLIES 격자로 드래그합니다.
   한 번에 최대 한 스택(붕대 5개, 물 2개, 탄약 60발)을 옮기며 기존 스택에 자동 합칩니다.
4. 휴대품 카드를 창고로 드래그하면 선택한 스택 전체를 보관합니다.
5. LOAD 버튼으로 창고 탄약을 사용해 소총 탄창을 최대 30발 장전합니다.
6. 스폰을 선택하고 **ENTER RAID (게임 진입)** 버튼을 누릅니다.
7. 결과 화면의 Return to Hideout으로 돌아와 다시 장비를 정리합니다.

화면은 전술 장비 화면을 참고한 어두운 올리브색 3단 레이아웃입니다.
왼쪽 캐릭터/의상 슬롯, 중앙 전술 장비와 휴대품 그리드, 오른쪽 품목별 창고 그리드를 배치하며,
상단 탭 형태의 섹션 표시와 하단 출전 선택·실행 버튼을 제공합니다.
캐릭터 실루엣과 자체 도형 아이콘을 사용하며 장비 이동은 드래그 앤 드롭으로 유지합니다.
넓은 화면에서는 3단 좌우 배치, 좁은 화면에서는 장비와 창고의 2단 배치로 전환합니다.
패널 내부는 스크롤할 수 있습니다. OVERVIEW/HEALTH/SKILLS/MAP/TASKS 탭은 시각 표시 전용입니다.
소총은 소총 슬롯에만, 보급품은 휴대품 격자에만 장착할 수 있습니다.
빈 공간이나 같은 보관 영역으로의 드롭은 수량을 변경하지 않습니다.
슬롯 내 자유 재배치·아이템 회전·다중 칸 점유 기능은 없으며 격자는 기존 12칸 인벤토리를 표시합니다.
창고 카드는 품목별 합산 수량을 표시합니다.
소총을 두고 가면 무장하지 않은 상태로 진입하며 1키를 눌러도 소총이 생기지 않습니다.
출전 장비는 소총 1정과 기존 12칸 보급품 인벤토리입니다. 방어구·헬멧은 기존 게임에 없으므로 이번 범위에 포함하지 않습니다.
캐릭터의 소총 메시도 실제 소지 여부에 맞춰 표시합니다.

## 회수·손실
- 정상 탈출: 인벤토리, 소총 소유권, 탄창 잔탄을 다음 출전 장비로 회수합니다. Store로 창고에 놓을 수 있습니다.
- 사망/MIA: 출전 장비와 획득 아이템을 잃습니다. 창고에 둔 물품은 유지합니다.
- 레이드 중 종료/비정상 종료: 출전 전에 저장한 창고만 복원됩니다. 레이드 중 장비는 회수하지 않습니다.
- 매 레이드마다 체력·수분·스태미나, AI, 전리품, 카메라, 타이머를 초기화합니다.
- 은신처에서는 레이드 타이머와 전투 업데이트를 진행하지 않습니다.

## 저장
작업 디렉터리의 Saves/hideout.txt에 창고 및 출전 준비 상태를 자동 저장합니다.
임시 파일 기록 후 Windows 파일 교체로 반영하며, 저장 실패 시 출전을 막고 알림을 표시합니다.
장비 이동 저장 실패는 해당 이동을 되돌립니다. 탈출 회수 저장 실패는 메모리에 유지하므로
은신처에서 Save / Retry를 누르거나 장비를 정리해 재저장한 뒤 종료해야 합니다.
손상된 저장 파일은 덮어쓰지 않고 출전을 막습니다.

첫 프로필에만 소총 3정, 붕대 10개, 물 8개, 탄약 180발을 제공합니다.
기존 industrial_zone_loot.txt는 과거 누적 기록이며 새 프로필로 자동 합산하지 않습니다.
이전 기록은 삭제하거나 수정하지 않습니다.

## 검증
요청에 따라 빌드·실행 없이 소스 연결, 프로젝트 XML 및 diff 공백 오류를 점검했습니다.
실행 시 아래를 확인해야 합니다.
- 창고↔출전 이동 후 재실행해 수량이 일치하는지.
- 소총을 두고 출전하면 사격/장착/소총 표시가 모두 차단되는지.
- 탄창 장전·발사·탈출·보관 시 탄약 총량이 보존되는지.
- 사망/MIA 후 창고만 남는지, 결과→은신처→재진입이 가능한지.
- 저장 실패 시 장비 이동이 취소되고 게임 진입이 차단되는지.
