# 은신처와 출전 장비

게임은 기존 ImGui HUD 기반 은신처 장비 화면으로 시작합니다. 넓은 화면에서는 캐릭터·인벤토리·창고를 3단으로, 좁은 화면에서는 캐릭터와 인벤토리·창고를 2단으로 표시합니다.

## 장비 준비

- 왼쪽 캐릭터 패널은 현재 장비 마스크를 반영한 3D 캐릭터 미리보기와 머리·상의·브라·배낭·전술조끼·하의·팬티 슬롯을 표시합니다. 슬롯을 누르면 착용/해제하고, 같은 종류의 아이템을 끌어 놓아도 장착할 수 있습니다.
- 브라/팬티 슬롯은 검은 스포츠 브라와 티팬티 외형으로 연결되어 있습니다. 상의나 하의를 벗으면 착용 중인 속옷 모델이 보이고, 다시 옷을 입으면 겉옷 아래로 가려집니다.
- 배낭은 컴팩트한 크기의 디지털 멀티캠 무늬와 앞 포켓·가로 웨빙 디테일을 가진 장착 모델입니다.
- 중앙 인벤토리에는 소총과 휴대 아이템을 표시합니다. 창고의 아이템을 끌어오면 출전 장비에 넣고, 인벤토리 스택을 창고로 끌어 놓으면 해당 스택을 보관합니다.
- 전술조끼는 휴대 슬롯 6칸, 배낭은 12칸을 추가합니다. 장착 해제 뒤 현재 아이템이 새 용량을 넘으면 먼저 인벤토리를 정리해야 합니다.
- 붕대·물·탄약은 기존 스택에 합쳐집니다. 한 번에 최대 한 스택을 옮기며(붕대 5개, 물 2개, 탄약 60발), 빈 슬롯을 클릭해도 아이템은 생성되지 않습니다.
- 창고는 안전 보관 영역이며 소총·소모품·의류·배낭을 저장합니다. 창고의 소총을 끌어 소총 카드에 장착하고, 장착된 소총을 창고 카드나 보관 영역으로 끌어 놓아 보관합니다.
- 탄창 장전 버튼은 창고 탄약을 소모해 소총을 최대 30발까지 채웁니다. 출격 지점을 선택한 뒤 **레이드 출격**을 누릅니다.

화면의 모든 은신처 안내·슬롯·버튼 문구는 한국어입니다. 상단의 전체·장비·건강·기술·지도·임무 탭 중 장비 외 탭은 화면 표시 전용입니다. 슬롯의 자유 재배치, 아이템 회전, 다중 칸 점유는 지원하지 않습니다.

## 회수·손실

- 정상 탈출: 인벤토리, 소총 소유권, 탄창 잔탄, 착용 의상을 다음 출전 장비로 회수합니다.
- 사망/MIA: 출전 장비와 획득 아이템을 잃습니다. 창고 물품은 유지합니다.
- 레이드 중 종료/비정상 종료: 출전 전에 저장한 창고만 복원됩니다.
- 매 레이드마다 체력·수분·스태미나, AI, 전리품, 카메라, 타이머를 초기화합니다. 은신처에서는 레이드 타이머와 전투 업데이트를 진행하지 않습니다.

## 저장

작업 디렉터리의 `Saves/hideout.txt`에 창고와 출전 준비 상태를 자동 저장합니다. 임시 파일을 기록한 뒤 Windows 파일 교체로 반영하며, 장비 이동 저장이 실패하면 해당 이동을 되돌립니다. 탈출 회수 저장 실패는 메모리에 유지하므로 은신처에서 **저장 / 재시도**를 누른 뒤 종료해야 합니다. 저장 파일이 손상되면 원본을 덮어쓰지 않고 출전을 막습니다.

테스트를 위해 새 프로필의 소총과 모든 아이템 종류를 창고에 각각 50개씩 지급합니다. 이전 은신처 저장 형식(v1~v5)을 불러오면 기존 수량을 유지하면서 소총과 각 아이템 50개를 한 번 추가 지급하고 새 저장 형식으로 기록합니다. 기존 `industrial_zone_loot.txt`는 새 프로필에 자동 합산하지 않습니다.

## 검증

요청에 따라 빌드·실행 없이 소스 연결과 diff 공백 오류만 점검했습니다. 실행 시 다음 항목을 확인해야 합니다.

- 의류·배낭·조끼 착용에 따라 캐릭터 외형과 인벤토리 용량이 갱신되는지.
- 창고↔인벤토리 이동 후 게임을 재시작해도 수량이 유지되는지.
- 소총을 두고 출전하면 사격·장착·소총 표시가 차단되는지.
- 탄창 장전·발사·탈출·보관 시 탄약 총량이 보존되는지.
- 사망/MIA 후 창고만 남고, 결과 화면에서 은신처로 복귀해 재출전할 수 있는지.
- 저장 실패 시 장비 이동이 취소되고 출전이 차단되는지.
