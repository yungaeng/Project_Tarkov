# 은신처와 출전 장비

게임은 ImGui 기반 은신처 화면으로 시작합니다. 장비 탭은 캐릭터·인벤토리·4×20 창고를, 건강 탭은 캐릭터와 피격 부위·창고를 표시합니다. 레이드 출격·저장·게임 종료 버튼은 화면 왼쪽 상단에 있고, 아래 작업 영역은 남은 화면 높이를 사용합니다.

## 장비 준비

- 장비 탭의 캐릭터 패널은 넓어진 캐릭터 미리보기와 반투명 머리·상의·브라·배낭·전술조끼·하의·팬티 슬롯을 표시합니다. 소총을 장착하면 캐릭터가 소총을 든 자세를 취하고 무기가 손에 맞춰 표시됩니다. 슬롯을 누르거나 창고 아이템을 클릭 또는 끌어 놓아 장착할 수 있습니다. 비장비 아이템은 클릭 시 휴대 인벤토리로 옮깁니다.
- 건강 탭에서 각 부위의 수치와 색상 상태를 확인하고 창고 붕대를 부위에 끌어 놓아 치료하거나, 붕대를 클릭해 치료 부위 선택 대화상자를 열 수 있습니다. 부위 체력은 20 회복되며 붕대 한 개를 소비합니다.
- 브라/팬티 슬롯은 캐릭터 신체 표면의 곡률과 크기에 맞춘 검은 스포츠 브라와 티팬티 외형으로 연결되어 있습니다. 상의나 하의를 벗으면 착용 중인 속옷 모델이 보이고, 다시 옷을 입으면 겉옷 아래로 가려집니다.
- 배낭은 캐릭터 체형에 맞춘 크기의 디지털 멀티캠 무늬와 앞 포켓·가로 웨빙 디테일을 가진 장착 모델입니다.
- 중앙 인벤토리에는 소총과 휴대 아이템을 표시합니다. 창고의 아이템을 끌어오면 출전 장비에 넣고, 인벤토리 스택을 창고로 끌어 놓으면 해당 스택을 보관합니다.
- 전술조끼는 휴대 슬롯 6칸, 배낭은 12칸을 추가합니다. 장착 해제 뒤 현재 아이템이 새 용량을 넘으면 먼저 인벤토리를 정리해야 합니다.
- 붕대·물·탄약은 기존 스택에 합쳐집니다. 한 번에 최대 한 스택을 옮기며(붕대 5개, 물 2개, 탄약 60발), 빈 슬롯을 클릭해도 아이템은 생성되지 않습니다.
- 창고는 레이드 손실로부터 보호되는 보관 영역입니다. 창고 격자의 소총을 장비 탭 소총 슬롯으로 끌어 장착하고, 장착된 소총을 격자로 끌어 보관합니다.
- 창고는 체스판 형태의 4×20 격자입니다. 화면 너비에 맞춰 슬롯 크기를 조정하고, 선명한 격자선과 세로 스크롤로 전체 4열×20행을 볼 수 있습니다. 내부 저장 배치와 아이템별 크기는 그대로 유지합니다. 붕대 등 작은 물품은 1×1, 물·탄약·의류·조끼·헬멧·배낭·소총은 크기에 맞는 여러 칸을 차지합니다. 아이템을 창고 격자 밖으로 끌어 보관하거나 창고에서 출전 장비로 끌어옵니다. 공간이 부족하면 격자에 들어가지 못한 아이템은 버립니다.
- 탄창 장전 버튼은 창고 탄약을 소모해 소총을 최대 30발까지 채웁니다. 출격 시 두 스폰 위치 중 하나를 무작위로 선택합니다. **레이드 출격**을 누르세요.

화면의 은신처 버튼과 슬롯 문구는 한국어입니다. 건강 탭은 피격 부위 표시와 창고 붕대 치료를 지원합니다. 슬롯의 자유 재배치와 아이템 회전은 지원하지 않습니다.

## 회수·손실

- 정상 탈출: 인벤토리, 소총 소유권, 탄창 잔탄, 착용 의상을 다음 출전 장비로 회수합니다.
- 사망/MIA: 출전 장비와 획득 아이템을 잃습니다. 창고 물품은 유지합니다.
- 레이드 중 종료/비정상 종료: 출전 전에 저장한 창고만 복원됩니다.
- 레이드마다 AI, 전리품, 카메라, 타이머를 초기화합니다. 피격 부위 체력·수분·스태미나는 은신처에 저장되며, 사망 상태에서는 치료 전까지 재출격할 수 없습니다.

## 저장

작업 디렉터리의 `Saves/hideout.txt`에 창고와 출전 준비 상태를 자동 저장합니다. 임시 파일을 기록한 뒤 Windows 파일 교체로 반영하며, 장비 이동 저장이 실패하면 해당 이동을 되돌립니다. 탈출 회수 저장 실패는 메모리에 유지하므로 은신처에서 **저장 / 재시도**를 누른 뒤 종료해야 합니다. 저장 파일이 손상되면 원본을 덮어쓰지 않고 출전을 막습니다.

새 프로필은 창고의 소총과 아이템 종류별로 최대 10개씩 시작합니다. 기존 저장(v1~v6)은 읽을 수 있으며 새 형식으로 변환할 때 종류별 수량을 10개, 전체 배치를 4×20 격자 용량에 맞춰 정리합니다. 피격 부위 체력·수분·스태미나도 저장됩니다. 기존 `industrial_zone_loot.txt`는 새 프로필에 자동 합산하지 않습니다.

## 검증

요청에 따라 빌드·실행 없이 소스 연결과 diff 공백 오류만 점검했습니다. 실행 시 다음 항목을 확인해야 합니다.

- 의류·배낭·조끼 착용에 따라 캐릭터 외형과 인벤토리 용량이 갱신되는지.
- 창고↔인벤토리 이동 후 게임을 재시작해도 수량이 유지되는지.
- 소총을 두고 출전하면 사격·장착·소총 표시가 차단되는지.
- 탄창 장전·발사·탈출·보관 시 탄약 총량이 보존되는지.
- 사망/MIA 후 출전 장비만 손실되고, 은신처에서 손상 부위를 치료한 뒤 재출격할 수 있는지.
- 저장 실패 시 장비 이동이 취소되고 출전이 차단되는지.
