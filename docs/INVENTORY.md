# 아이템 줍기와 인벤토리

- 바닥의 빨간 상자(붕대), 파란 상자(물), 갈색 상자(탄약)를 조준하고 F를 누르면 줍습니다.
- 캐릭터 눈 위치에서 아이템 중심까지 2.5m 이내여야 합니다. 가까이 이동하고 마우스로 바닥을 내려다보세요.
- 화면 중앙 조준점으로 선택하며, 선택된 아이템은 노란색으로 표시됩니다.
- 카메라와 아이템 사이 또는 캐릭터와 아이템 사이에 월드 장애물이 있으면 주울 수 없습니다.
- I를 누르면 인벤토리 목록과 수량·무게를 확인합니다. 열린 동안 이동과 줍기는 차단됩니다.
- 슬롯은 12개이며 붕대는 5개, 물은 2개, 탄약은 60개까지 한 슬롯에 겹칩니다.
- 기존 묶음을 먼저 채운 후 새 슬롯을 사용합니다. 전체 수량을 넣을 공간이 없으면 아무것도 옮기지 않고 월드에 남깁니다.
- F를 누르고 있어도 한 번만 처리하며 다시 주우려면 키를 놓았다가 누릅니다.

## 구조

- Inventory: 좌표·렌더링 없는 아이템 데이터, 묶음 및 슬롯 관리. Player가 소유합니다.
- WorldItem: 월드 위치와 아이템 묶음. LootSystem이 소유합니다.
- LootSystem: 조준·거리·가림 판정 후 인벤토리 추가 성공 시 월드 아이템 제거.
- RaidHud: ImGui로 조준 안내와 인벤토리 표 출력. UI 문자열은 기본 폰트에 맞춘 영어입니다.
- Physics/Raycast.h: 월드 및 아이템 AABB의 광선 교차 판정.

시작 지점 앞에 붕대 2개, 물 1개, 탄약 30개·40개를 배치합니다.
탄약 두 묶음을 모두 주우면 60개와 10개로 나뉩니다.
무게는 표시용이며 이동 제한, 사용·버리기·저장/불러오기는 아직 포함하지 않습니다.
인벤토리는 현재 레이드의 Player에 속하며 장면 종료 시 초기화됩니다.

## 검증 상태

사용자 요청대로 빌드·실행·패키지 복원은 수행하지 않았습니다.
프로젝트 파일 등록, include 경로와 데이터 이전·수명 관리 흐름을 정적으로 확인했습니다.
다음 빌드에서는 vcpkg가 ImGui와 GLFW/OpenGL3 바인딩을 복원해야 합니다.

실행 확인 항목:

1. 시작 지점 주변 아이템을 F로 줍고 월드에서 사라지는지 확인.
2. I로 이름·수량·무게를 확인하고 다시 닫았을 때 이동과 마우스 시점이 복구되는지 확인.
3. 탄약 30개와 40개를 순서와 관계없이 주워 60/10으로 나뉘는지 확인.
4. 벽 뒤, 거리 밖, 인벤토리 열린 상태, 비활성 창에서는 줍기가 불가능한지 확인.
5. 슬롯을 가득 채운 검증 데이터에서 실패 시 인벤토리와 월드 수량이 그대로인지 확인.
6. F를 누른 채 Alt+Tab 후 복귀해 추가 줍기가 발생하지 않는지 확인.
7. 최소화·복원, F11, 장면 종료 시 UI와 커서 상태를 확인.
