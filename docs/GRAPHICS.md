# 그래픽 렌더링

현재 OpenGL 3.3 렌더러는 다음 기본 화면 효과를 적용합니다.

- 창 생성 시 4× MSAA를 요청하고, 렌더러에서 멀티샘플링을 활성화해 기하 모서리의 계단 현상을 줄입니다. 드라이버가 해당 샘플 수를 제공하지 않으면 기본 프레임버퍼 설정을 사용합니다.
- 캐릭터 텍스처는 sRGB 형식으로 업로드하고 선형 공간에서 조명합니다. 셰이더는 ACES 톤매핑과 sRGB 출력 변환을 적용해 밝은 면과 색상 범위를 부드럽게 표현합니다.
- 위쪽 하늘색 주변광, 따뜻한 방향광, 약한 보조광으로 면의 명암을 만듭니다.
- 카메라에서 85m부터 안개를 섞기 시작해 235m에서 배경색으로 수렴합니다. 짧은 거리의 은신처 캐릭터 미리보기에는 안개가 거의 적용되지 않습니다.

셰이더 파일은 게임 실행 중 변경 시 다시 로드됩니다. MSAA 동작은 그래픽 드라이버와 창 프레임버퍼가 샘플 버퍼를 지원하는지에 따라 달라질 수 있습니다.
